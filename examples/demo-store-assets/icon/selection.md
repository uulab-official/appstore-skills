# Icon candidate selection

## Batch

Six independent candidates were generated from the Example App context:

| Candidate | Direction | Read at 32×32 | Decision |
| --- | --- | --- | --- |
| A1 | Symbolic check + spark ring | Yes | Keep as alternate |
| A2 | Symbolic check + rounded visibility window | Yes | Selected for demo |
| B1 | Friendly coral task companion | Mostly | Keep as character direction |
| B2 | Friendly cobalt task companion | Mostly | Keep as character direction |
| C1 | Abstract organized card stack | Yes | Keep as alternate |
| C2 | Abstract focus window | Yes | Keep as alternate |

## Selection rationale

Select **A2** because its rounded window and checkmark communicate visibility,
progress, and task completion with the fewest shapes. It remains clear at
180px and 32px, preserves the Example App cobalt/coral palette, and avoids
character details that disappear at small sizes.

## Review status

This is a demo selection, not production approval. Confirm trademark
distinctiveness, platform treatment, and product-owner approval before using it
outside this fixture.
