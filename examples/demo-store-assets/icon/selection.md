# Icon candidate selection

## Batch 1 — rejected as generic

The first six-candidate batch was preserved, but it was not promoted because
the strongest result depended on a checkmark inside a rounded window. That
communicates category and completion quickly, but it is not distinctive enough
to serve as an ownable product mark.

## Batch 2 — rejected as too flat

The second batch improved distinctiveness but still depended on flat geometric
forms. It was retained as a useful exploration, not promoted as the store
icon.

## Batch 3 — rejected as under-specified

Six independent candidates were generated from the Example App context with
literal category symbols excluded and a premium 3D art direction:

| Candidate | Direction | Read at 32×32 | Decision |
| --- | --- | --- | --- |
| A1 | Asymmetric cobalt portal with coral core | Yes | Keep as reference |
| A2 | Coral visor companion | Yes | Keep as alternate |
| B1 | Folded cobalt cradle | Yes | Keep as alternate |
| B2 | Cobalt doorway sculpture | Mostly | Keep as alternate |
| C1 | Coral focus stone with cobalt ribbon | Yes | Keep as alternate |
| C2 | Cobalt shelter with coral core | Yes | Keep as alternate |

Batch 3 established the dimensional finish but still treated the object as a
simple shell-and-core composition. It was not promoted because the user asked
for richer, intentional construction details that follow from the design brief.

## Batch 4 — selected direction

The fourth batch used the brief's explicit component map: outer shell,
recessed cavity, priority capsule, inset panel, and task-capture tab.

| Candidate | Direction | Read at 32×32 | Decision |
| --- | --- | --- | --- |
| A1 | Layered portal with capsule and capture tab | Yes | Selected and refined |
| A2 | Open shell with coral core and capture tab | Yes | Keep as alternate |
| B1 | Engineered chamber with horizontal core | Yes | Reject: reads like a device |
| B2 | Folded cradle with inner coral bowl | Yes | Reject: generic container |
| C1 | Aperture dial with coral marker | Yes | Reject: generic dial/ring |
| C2 | Open shell with layered coral lens | Yes | Reject: reads like an earbud |

## Selection rationale

Select **A1 v4** because it is the only candidate whose component hierarchy
survives at both scales: the blue shell carries the silhouette, the recessed
cavity creates depth, the coral capsule communicates the priority task, and
the flat coral capture tab adds a product-specific cue without becoming
hardware. It is detailed at 180px but resolves to a clean asymmetric mark at
32px. The final refinement removed the cylindrical hinge that made the earlier
version resemble an earbud case.

## Review notes

- The generated candidates remain available under `concepts-v4/` for audit and
  future iteration.
- The 3D refinement is a demo-quality direction, not a trademark claim.
- The first three batches remain under `concepts/`, `concepts-v2/`, and
  `concepts-v3/` to show why the input-fidelity and component-detail gates
  exist.

## Review status

This is a demo selection, not production approval. Confirm trademark
distinctiveness, platform treatment, and product-owner approval before using it
outside this fixture.
