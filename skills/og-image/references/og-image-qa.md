# OG image QA checklist

## Content checks

- Confirm the title, description, product name, and visual claim match the
  linked page.
- Confirm the locale matches the page or requested campaign locale.
- Remove private data, internal URLs, secrets, and unsupported claims.
- Check that the brand mark is approved and the contrast is accessible.

## Rendering checks

- Inspect at full-size, thumbnail-size, and a narrow crop.
- Check the safe area around every headline and logo.
- Confirm no type, logo, or UI element is clipped or dependent on hover.
- Confirm the output color profile, file format, dimensions, and file size.
- Check both light and dark surrounding contexts when the channel supports
  them.

## Metadata and deployment checks

- Confirm the `og:image` URL is absolute and publicly reachable in the target
  environment.
- Confirm the page title, description, and image reference are consistent.
- Check cache or preview refresh behavior when the platform provides a
  debugging tool.
- Record the channels and current documentation checked in the delivery
  report.
